┌─ 1️⃣  CARGA DE DOCUMENTOS 📄 ────────────────────────────────────────────┐
│                                                                           │
│  ¿QUÉ ES?                                                                │
│  Los ingenieros suben 3 documentos PDF cuando se registran               │
│                                                                           │
│  DOCUMENTOS:                                                             │
│  • CV (Currículum)                                                       │
│  • DNI (Copia de documento)                                              │
│  • Carnet de Colegio de Ingenieros                                       │
│                                                                           │
│  ¿CÓMO FUNCIONA?                                                         │
│  1. Ingeniero va a /onboarding                                           │
│  2. Sube los 3 documentos (máx 10MB)                                      │
│  3. Se guardan en Supabase Storage                                       │
│  4. Admin puede revisarlos                                               │
│                                                                           │
│  ¿PARA QUÉ?                                                              │
│  Validar que los ingenieros son reales y profesionales                   │
│                                                                           │
└───────────────────────────────────────────────────────────────────────────┘


┌─ 2️⃣  PANEL DE ADMINISTRADOR 👨‍💼 ────────────────────────────────────────┐
│                                                                           │
│  ¿QUÉ ES?                                                                │
│  Un panel especial solo para administradores                             │
│                                                                           │
│  SECCIONES:                                                              │
│  • Panel Principal: Estadísticas y resumen                               │
│  • Ingenieros: Lista de todos los ingenieros                             │
│  • Clientes: Lista de todos los clientes                                 │
│  • Documentos: Revisar y verificar PDFs                                  │
│                                                                           │
│  ¿CÓMO FUNCIONA?                                                         │
│  1. Admin accede a /dashboard/admin                                      │
│  2. Ve estadísticas y opciones                                           │
│  3. Puede revisar ingenieros, clientes y documentos                      │
│  4. Puede verificar ingenieros                                           │
│                                                                           │
│  ¿PARA QUÉ?                                                              │
│  Gestionar y verificar a todos los usuarios                              │
│                                                                           │
└───────────────────────────────────────────────────────────────────────────┘


┌─ 3️⃣  VERIFICACIÓN (CHECK AZUL) ✅ ──────────────────────────────────────┐
│                                                                           │
│  ¿QUÉ ES?                                                                │
│  Un badge azul que aparece en perfiles de ingenieros verificados         │
│                                                                           │
│  ¿CÓMO FUNCIONA?                                                         │
│  1. Admin revisa documentos del ingeniero                                │
│  2. Si todo está bien, hace clic en "Verificar"                          │
│  3. Badge azul ✓ aparece en el perfil                                    │
│  4. Clientes ven que es confiable                                        │
│                                                                           │
│  ¿PARA QUÉ?                                                              │
│  Que los clientes sepan que el ingeniero es verificado y confiable       │
│                                                                           │
│  BENEFICIO:                                                              │
│  Más confianza = Más proyectos para el ingeniero                         │
│                                                                           │
└───────────────────────────────────────────────────────────────────────────┘


┌─ 4️⃣  BOTÓN DE WHATSAPP 📱 ──────────────────────────────────────────────┐
│                                                                           │
│  ¿QUÉ ES?                                                                │
│  Un botón que abre WhatsApp automáticamente                              │
│                                                                           │
│  ¿CÓMO FUNCIONA?                                                         │
│  1. Cliente ve perfil del ingeniero                                      │
│  2. Hace clic en "Contactar por WhatsApp"                                │
│  3. Se abre WhatsApp con el número del ingeniero                         │
│  4. Cliente envía mensaje                                                │
│                                                                           │
│  ¿PARA QUÉ?                                                              │
│  Contacto rápido y fácil entre clientes e ingenieros                     │
│                                                                           │
│  NOTA:                                                                   │
│  Solo funciona con números de Perú (+51)                                 │
│                                                                           │
└───────────────────────────────────────────────────────────────────────────┘


┌─ 5️⃣  SISTEMA DE FAVORITOS ❤️ ──────────────────────────────────────────┐
│                                                                           │
│  ¿QUÉ ES?                                                                │
│  Los usuarios pueden marcar ingenieros como favoritos                    │
│                                                                           │
│  ¿CÓMO FUNCIONA?                                                         │
│  1. Cliente ve perfil de ingeniero                                       │
│  2. Hace clic en botón corazón ❤️                                        │
│  3. Ingeniero se agrega a favoritos                                      │
│  4. Cliente puede verlos después en su dashboard                         │
│                                                                           │
│  ¿PARA QUÉ?                                                              │
│  Guardar ingenieros favoritos para acceso rápido                         │
│                                                                           │
│  BENEFICIO:                                                              │
│  Clientes encuentran rápido sus ingenieros preferidos                    │
│                                                                           │
└───────────────────────────────────────────────────────────────────────────┘


┌─ 6️⃣  SISTEMA DE RESEÑAS ⭐ ──────────────────────────────────────────────┐
│                                                                           │
│  ¿QUÉ ES?                                                                │
│  Los usuarios dejan reseñas y calificaciones a los ingenieros            │
│                                                                           │
│  ¿CÓMO FUNCIONA?                                                         │
│  1. Después de un proyecto, cliente escribe reseña                       │
│  2. Califica con estrellas (1-5):                                        │
│     • Comunicación                                                       │
│     • Calidad del trabajo                                                │
│     • Puntualidad                                                        │
│     • Profesionalismo                                                    │
│  3. Agrega título y comentario (opcional)                                │
│  4. Reseña aparece en perfil del ingeniero                               │
│                                                                           │
│  ¿PARA QUÉ?                                                              │
│  Que otros clientes vean experiencias de otros usuarios                  │
│                                                                           │
│  BENEFICIO:                                                              │
│  Más reseñas = Más confianza = Más proyectos                             │
│                                                                           │
└───────────────────────────────────────────────────────────────────────────┘
